# 验证与安全

设置页状态、详情面板和“应用”按钮共用同一份验证结果，不存在“忽略错误强制应用”的入口。

## 错误与警告

| 级别 | 效果 |
|---|---|
| 错误 | 禁用应用，修正前无法应用。 |
| 警告 | 允许应用，但规则存在限制或部分子项被跳过。 |
| 通过 | 规则有效。 |

## 常见错误

- **目标路径已存在。** 重定向会产生重复菜单路径。
- **原路径没有可执行静态 `[MenuItem]`。** 原菜单可能是动态注册、已不存在，或容器下没有可执行子项。
- **原路径和目标路径重叠。** 不能把菜单移动到自身内部，或移动到另一条规则要移除的路径下。
- **原路径重复。** 两条规则不能移除同一个原路径。
- **路径格式非法。** 空段（`//`）、首尾分隔符等格式会被拒绝。
- **原路径或目标路径受保护。** Unity 内置菜单和 Unity 官方条目不能被移除或移动。
- **分支没有可执行子项。** 分支搬移至少需要一个可执行子项。

## 常见警告

- 原路径是动态注册菜单，只能隐藏，不能重定向。
- 分支中包含受保护子项，这些子项会被跳过并保留。
- 目标父级受保护，但叶子本身仍可创建。

## 受保护容器

嵌套容器如果包含 Unity 程序集声明的菜单，整体受保护。
工具不会移除整个容器；分支搬移会跳过受保护子项并保留其内容。

## 旧配置或被绕过的配置

即使配置由旧版本写入或在设置页之外被修改，工具也会在域重载重放前重新验证路径和目标。
如果替代入口未就绪，不会隐藏原菜单。

## 事务式文件处理

应用过程尽量避免中间状态：

- 先写新包装；
- 再保存配置；
- 保存成功后才删除旧包装；
- 保存失败回滚新文件；
- 旧文件删除失败时撤销新文件并保留旧路径；
- 目标位置的非生成文件不会被覆盖；
- 存在多个残留生成文件时中止操作。

## 生成头

只有首行包含本工具生成头的文件才被视为受管理文件。
用户自己创建的同名 `MenuRedirects.g.cs` 不会被改动。

## 不验证的内容

- **快捷键**不会复制。工具会提示并列出快捷键，但无法重建 Unity 的编译期快捷键行为。
- **动态菜单**不能重定向。请先改为静态 `[MenuItem]`，或使用仅隐藏。
- **运行时行为**不在工具范围内；这是纯编辑器工具。

## 恢复

如果应用失败，先阅读反馈区。配置和生成文件会保持在上一个一致状态。如果不确定：

1. 打开设置页。
2. 检查生成代码状态。
3. 在 Console 中修复编译错误。
4. 再次点击 **应用**。
5. 必要时执行清理命令，然后重新应用。
