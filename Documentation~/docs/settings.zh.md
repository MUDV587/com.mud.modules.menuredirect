# 设置页

打开方式：**Edit > Project Settings > MUD > Menu Redirect**，或 **Tools > MUD > Menu Redirect**。

## 布局

页面使用左右两栏：

- **左栏**：规则列表、搜索、筛选、Add、导入、导出、应用、还原。
- **右栏**：选中规则的详情，包括路径、优先级、验证结果和状态。
- **底部**：应用反馈和生成代码状态。

拖动两栏之间共用的 1px 黑色分割线可以调整宽度——分割线上叠加的是 6px 宽的不可见拖拽热区，
拖动反馈只有黑线和左右箭头光标（不再绘制高亮），右栏内容更靠近分割线。左栏最小 220 px，
右栏最小 240 px。分隔条宽度不持久化，离开页面或域重载后恢复默认。

## 工具栏

工具栏显示四类计数：

- 已启用规则数；
- 验证通过数；
- 警告数；
- 错误数。

计数只在验证结果变化时更新，不会在每个 GUI 事件中重新扫描全部规则。

## 搜索与筛选

搜索框按原路径/新路径做不区分大小写的子串匹配。

**仅显示问题** 只保留有警告或错误的规则。筛选结果为空时，列表显示空状态和 **清除筛选** 按钮。

有筛选时禁用拖动排序。新增、导入或还原会自动清除筛选。

## 规则操作

- **Add**：新建一条未启用规则。
- **导入…**：从 JSON 文件整体替换当前内存规则，操作前会确认。
- **导出…**：把当前内存规则写入 JSON 文件。
- **应用**：保存配置并生成包装代码。
- **还原**：丢弃未保存的内存修改，恢复到上次应用的状态。

导入、导出和选择器都只修改内存；必须点击 **应用** 才会写配置或生成代码。

## 生成代码目录

**生成代码** 行控制 `MenuRedirects.g.cs` 的写入位置。目录必须在 `Assets` 下，
并且路径中包含名为 `Editor` 的目录。文件名固定，不能修改。

**选择…** 选择目录，**打开目录** 在文件管理器中定位，**恢复默认** 回到
`Assets/MenuRedirects/Editor`。

修改目录会标记未保存；应用时会把生成文件迁移到新目录。

## 语言

语言下拉框支持 **跟随系统**、**中文**、**English**。偏好按项目保存在 `EditorPrefs`，
不写入 `MenuRedirect.asset`。切换语言不会标记未保存、保存配置或触发包装代码重编译。

## 未保存状态

页面会显示是否存在未保存修改，以及是否等待重新编译。如果 Unity 崩溃或域重载，
可以从 `Library/MenuRedirectDraft.json` 恢复草稿。详见[草稿恢复](drafts.md)。

## 反馈区

应用结果、生成代码状态和隐藏消息显示在左右分栏下方，使用 HelpBox 样式。
反馈区出现或消失只改变分栏底部可用高度，不会把整页内容向下推。

如果生成代码过期或缺失，隐藏会被有意推迟，反馈区会说明原因并提示完成编译或重新应用。
