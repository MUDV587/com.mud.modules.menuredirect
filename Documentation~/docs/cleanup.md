# Cleanup & Uninstall

Unity does not provide a reliable callback after a package is removed. Clean up generated files
**before** uninstalling.

## Recommended cleanup

1. Keep the package installed.
2. Run **Tools > MUD > Menu Redirect > Clean Up Generated Files**.
3. Review the confirmation dialog. It lists generated files in the current and last configured folders.
4. Confirm.

The command only deletes files that:

- are named `MenuRedirects.g.cs`;
- are inside `Assets`;
- have this tool's generated header on the first line.

User files and files with other names are not deleted.

`ProjectSettings/MenuRedirect.asset` is kept. Your rules are not lost.

After deletion, the original menus return after the next domain reload. If you continue using the
tool, open the settings page and click **Apply** to generate the wrappers again.

## Manual cleanup

If the package is already removed:

1. Delete the generated file:
   `Assets/MenuRedirects/Editor/MenuRedirects.g.cs`, or the file in your custom folder.
2. Before deleting, confirm the first line contains:
   `// <auto-generated>由 MUD Menu Redirect 生成，请勿手动修改。</auto-generated>`
3. If you want to remove the rules too, delete `ProjectSettings/MenuRedirect.asset`.
4. Wait for the next domain reload. The generated menus disappear and the original menus return.
5. Optionally remove empty folders left behind.

Do not delete a file named `MenuRedirects.g.cs` that does not have the generated header. It is a user
file, and the tool never manages it.

## What is kept

- `ProjectSettings/MenuRedirect.asset` — rules and generated-folder setting.
- `Library/MenuRedirectDraft.json` — local unsaved draft; safe to delete after uninstalling.
- `EditorPrefs` language preference — local, per project; harmless to leave.

## Reinstalling

If you reinstall later, the saved configuration is still present. Open the settings page and click
**Apply** to regenerate the wrapper code.

## Removing the package

After cleanup, remove the package through **Package Manager** or remove its entry from
`Packages/manifest.json`. Unity will recompile without the editor assembly.

If the original menus do not return, force a domain reload or restart Unity. If a generated file
remains, delete it manually and reload again.
