# 菜单选择器

选择器是可搜索的菜单树，用于选择原路径和目标父级路径。

## 打开方式

- **原路径**：点击原路径字段右侧的 **选择…**。
- **目标父级**：点击新路径字段右侧的 **父级…**。

两种模式共用缓存的菜单注册表。除非点击刷新，否则每次打开不会重新扫描整个工程。

## 原路径模式

原路径模式列出：

- 所有已注册菜单路径；
- 所有中间容器，包括自身未注册的容器；
- 这些容器的子项。

选择只修改内存中的规则。需要点击 **应用** 才会保存并生成代码。

## 父级模式

父级模式只列出：

- 顶级路径；
- 有子项的容器。

对于分支规则，选中的父级直接作为新路径。

对于叶子规则，工具会保留当前新路径的最后一段；如果新路径为空，则沿用原路径的最后一段。
这样可以在不重新输入名称的情况下把叶子移动到新父级下。

如果原路径为空，选择父级后只填入父级，并提示补全新菜单名称。

## 状态图标

| 图标 | 含义 |
|---|---|
| 绿色对勾 | 可执行菜单项。 |
| 黄色 `!` | 仅隐藏，或包含受保护子项。 |
| 红色 `✕` | Unity 受保护条目，不可选。 |
| 灰色横线 | 禁用或不可用条目。 |

受保护条目可以悬停查看，但不能选择。

## 搜索

搜索按完整路径做不区分大小写的匹配。命中项会自动展开祖先。
清空搜索后恢复正常树状态。

## 键鼠操作

- 单击整行展开/折叠。
- 双击整行选中。
- `↑` / `↓` 移动键盘焦点。
- `Enter` 选中当前焦点行。
- `Esc` 关闭选择器。
- 刷新按钮重建菜单注册表。

单击不会移动深蓝色的“当前值”标记；该标记表示规则当前已设置的路径。
悬停使用浅蓝色单独显示。

## 动态菜单

动态注册的菜单不会出现在注册表中，需要手动输入路径。它们可以隐藏，但不能重定向。
