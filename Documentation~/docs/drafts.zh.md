# 草稿恢复

Menu Redirect 会保护未保存修改，避免崩溃或域重载丢失输入。

## 草稿位置

```text
Library/MenuRedirectDraft.json
```

`Library/` 是本机目录，不会提交到版本库。

## 写入时机

规则或生成目录变化后，页面标记为未保存并安排写盘。写盘有 **0.75 秒防抖**。
离开页面、域重载或退出编辑器时，会同步落盘。

拖动分隔条期间，验证和草稿写盘会推迟到松开鼠标后执行，避免同步校验或文件 IO 打断拖动。

## 内容

草稿保存两份快照：

- **已保存基线**：上次应用时的规则 JSON 和生成目录；
- **草稿**：当前内存中的规则 JSON 和生成目录。

基线用于判断草稿是否仍然有效。

## 恢复行为

页面打开时，工具比较草稿基线和当前配置。如果一致，则恢复草稿，并提示“已恢复上次未保存的修改”。

如果基线不一致，说明配置已在其它会话中被应用或还原，旧草稿失效，不会覆盖当前配置。

## 草稿校验

草稿即使包含暂时非法的路径也会恢复。这是有意的：崩溃不应该丢失输入到一半的路径。
恢复后仍会执行正常验证，错误修正前应用按钮保持禁用。

## 清除草稿

成功 **应用** 或 **还原** 后会删除草稿。草稿不属于包内容，不应提交。

## 故障排查

如果旧草稿反复出现：

1. 完成或还原当前编辑。
2. 点击 **应用** 或 **还原** 清除草稿。
3. 如果文件损坏，关闭 Unity 后删除 `Library/MenuRedirectDraft.json`。

删除草稿只会丢失未保存编辑，不会影响 `ProjectSettings/MenuRedirect.asset` 或生成代码。
