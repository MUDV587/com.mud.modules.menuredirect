# 清理与卸载

Unity 没有可靠的包卸载后回调，因此必须在**移除包之前**清理生成文件。

## 推荐清理方式

1. 保持包处于安装状态。
2. 执行 **Tools > MUD > Menu Redirect > Clean Up Generated Files**。
3. 查看确认框。它会列出当前配置目录和上次生成目录中的生成文件。
4. 确认删除。

命令只会删除满足以下条件的文件：

- 文件名是 `MenuRedirects.g.cs`；
- 位于 `Assets` 下；
- 首行带本工具生成头。

用户文件、其它文件名不会被删除。

`ProjectSettings/MenuRedirect.asset` 会保留，规则不会丢失。

删除后，下一次域重载会恢复原菜单。如果继续使用工具，打开设置页点击 **应用** 即可重新生成。

## 手动清理

如果包已经移除：

1. 删除生成文件：
   `Assets/MenuRedirects/Editor/MenuRedirects.g.cs`，或你自定义目录中的同名文件。
2. 删除前确认首行是：
   `// <auto-generated>由 MUD Menu Redirect 生成，请勿手动修改。</auto-generated>`
3. 如需彻底移除规则，再删除 `ProjectSettings/MenuRedirect.asset`。
4. 等待下一次域重载。生成菜单消失，原菜单恢复。
5. 可选：删除残留空目录。

不要删除没有生成头的 `MenuRedirects.g.cs`。那是用户文件，工具不会管理它。

## 会保留的内容

- `ProjectSettings/MenuRedirect.asset`：规则和生成目录设置。
- `Library/MenuRedirectDraft.json`：本机未保存草稿，卸载后可以删除。
- `EditorPrefs` 语言偏好：本机按项目保存，可以保留。

## 重新安装

以后重新安装时，保存的配置仍然存在。打开设置页点击 **应用** 即可重新生成包装代码。

## 移除包

清理完成后，通过 **Package Manager** 移除包，或从 `Packages/manifest.json` 删除条目。
Unity 会重新编译，不再包含编辑器程序集。

如果原菜单没有恢复，强制域重载或重启 Unity。如果仍有生成文件残留，
手动删除后再次重载。
