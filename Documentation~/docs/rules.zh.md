# 规则与路径

一条规则把原菜单路径映射到可选的新路径。

## 字段

| 字段 | 含义 |
|---|---|
| 启用 | 未启用的规则保留在列表中，但不参与验证和应用。 |
| 原路径 | 要隐藏或移动的已有菜单路径。 |
| 新路径 | 新菜单路径；留空表示仅隐藏。 |
| 优先级 | 传给生成包装的 `MenuItem` 优先级；数值越小，同级菜单越靠前。 |

优先级不影响规则在左侧列表中的顺序；列表顺序通过拖动调整。

## 四种常见规则

### 叶子重定向

```text
NuGet/Manage NuGet Packages  →  Tools/My Tools/Manage NuGet Packages
```

叶子是已注册为菜单项的路径。原菜单被隐藏，新路径生成包装菜单。

### 隐藏叶子

```text
NuGet/Manage NuGet Packages  →  （空）
```

菜单项被移除，不生成包装。

### 搬移分支

```text
NuGet  →  Tools/My Tools
```

分支指不带 `/` 的顶级路径，或自身未注册为菜单项但有已注册子项的容器。
工具会扫描所有可执行子项，在新父级下生成包装，并保留相对层级结构。

受保护子项会被跳过，并在验证结果和生成代码注释中说明。

### 隐藏分支

```text
NuGet  →  （空）
```

直接移除父路径，一次移除整棵子树。如果分支中含 Unity 内置子项，规则会报错，
不会为了隐藏父级而移除内置菜单。

## 分支判定

- 不带 `/` 的路径按分支容器处理。
- 带 `/` 的路径，如果有已注册子项且自身未注册，按分支处理。
- 自身已注册 `[MenuItem]` 的路径按叶子处理，即使它同时有子菜单。

这样可以避免把“菜单项 + 子菜单”误判为纯容器。

## 受保护菜单

Unity 内置顶级菜单（File、Edit、Assets、GameObject、Window、Help 等）以及由 Unity 程序集声明的条目
受保护，不能被隐藏或移动。

嵌套容器如果包含 Unity 声明的子项，整体受保护。分支搬移会跳过受保护子项并保留其内容。

`Tools` 根菜单**不受保护**，第三方/自定义工具可以搬移或隐藏。

Unity 归属根据程序集位置、`PackageInfo` 和 asmdef/asmref 路径判断。
程序集名以 `Unity` 开头但属于工程或第三方包时，不会被自动视为 Unity 所有。

## 动态菜单和上下文菜单

- 动态注册的菜单可以隐藏，但不能重定向。重定向需要静态 `[MenuItem]` 方法才能生成包装。
- Unity 声明的上下文菜单（`CONTEXT/...`）受保护；第三方上下文菜单可以选择和重定向，
  执行时用当前选中对象构造 `MenuCommand`。

## 快捷键

生成的包装不会复制原快捷键。Unity 的 `MenuItem` 快捷键是编译期特性，包装无法自动复现。

生成代码变化时，工具会在受影响的方法前写入注释，并在应用反馈中列出快捷键数量和按键。
需要时请手动为新菜单添加快捷键。

## 验证

规则必须通过验证才能应用。常见错误：

- 目标路径已存在；
- 原路径没有可执行静态 `[MenuItem]`；
- 规则重叠或生成重复目标；
- 路径格式非法；
- 分支没有可执行子项；
- 原路径或目标路径受保护。

隐藏动态注册菜单属于警告，不阻止应用。

完整行为见[验证与安全](validation-safety.md)。
